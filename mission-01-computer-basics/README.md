# Mission 1 - Computer basics and IPOS

## 1. Task / objective
Trace an everyday activity through IPOS and identify hardware, software and computer-based systems.

## 2. Work completed
### 1.1 Saving a text document

| Stage | What happens | Component |
| --- | --- | --- |
| Input | Keys are pressed to enter a sentence. | Keyboard |
| Processing | The editor handles the keystrokes and updates the document in memory. | CPU and RAM |
| Output | The sentence appears on the screen. | Display |
| Storage | Saving writes the document to a file so it can be opened later. | SSD |

Typing changes the document held in memory. The screen shows those changes, but saving is a separate step that keeps the file after the app closes.

## 4. My understanding
IPOS stands for input, processing, output and storage. Hardware is the physical equipment; software is the set of instructions running on it. RAM holds working data while programs run, whereas an SSD keeps saved files when the power is off. A computer does not have to look like a laptop: an ATM also receives input, processes it and produces output.
